## 我们深度理解三件事

一是，CBP的真实审查标准——哪类证据在CBP眼里有效、哪类证据看起来厚但实际是废纸、拒绝入境率上升背后的证据门槛变化。

二是，风险真正藏在哪里——不在企业能看到的地方，在二级供应商、三级供应商的配棉记录里，在外协厂的缝纫线来源里，在股东结构里，在一个价值不到整车0.1%的电子元件里。

三是，执法趋势在往哪里走——今天是光伏，明天是电池，后天是关键矿产；今天查大批量高货值，明天查深层级小零部件。我们知道下一个高风险节点在哪里，不是等CBP公布之后才告诉你。
