## 我因此理解什么

**CBP的真实审查标准**
哪类证据在CBP眼里有效，哪类证据看起来厚实、实际是废纸。拒绝货物入境的背后，证据门槛如何随执法节奏悄然变化。

**风险真正藏在哪里**
不在企业能看到的地方。在Tier 2、Tier 3的配棉记录里，在外协厂的缝纫线来源里，在股东结构里，在一个价值不到整车0.1%的电子元件里。投资经验告诉我：企业最危险的风险，往往是管理层自己也没意识到的那种。

**执法趋势往哪里走**
今天是光伏，明天是电池，后天是关键矿产。今天查大批量高货值，明天查深层级小零部件。我知道下一个高风险节点在哪里——不是等CBP公布之后才告诉你。
